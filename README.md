##### 🛠️ setting up

this repo is essentially just a collection of `.md` (markdown) files that i maintain in [obsidian](https://obsidian.md/). you'll need to create your own vault in obsidian, install the `Git` community plugin and clone this repo by opening the command palette (`Ctrl` + `P`) and selecting the `Git: Clone an existing remote repo` option. also note that this repo contains my plugins and its configurations
